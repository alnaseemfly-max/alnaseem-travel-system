# نظام النسيم للسفريات — الإصدار الثاني

تم تطوير النظام ليشمل:
- لوحة تحكم وإحصائيات.
- إدارة العملاء والبحث والتعديل والحذف.
- إدارة المعاملات مع حالات ومبالغ وتواريخ.
- تعديل وحذف المعاملات.
- حجز الباصات لشركات: درة المدينة، الأفضل، المتصدر، النجار.
- متابعة حالة حجز الباص.
- تقارير مالية حسب الخدمة.
- يعمل على الجوال والمتصفح.
- جاهز للنشر على Render باستخدام Gunicorn.

## Render
Build Command:
pip install -r requirements.txt

Start Command:
gunicorn app:app

لا تحتاج لإضافة متغيرات بيئية في النسخة التجريبية.
