# نظام النسيم للسفريات — الإصدار المطوّر

نظام عربي متجاوب لإدارة مكتب السفر، ويعمل على الجوال والكمبيوتر. يحتوي على لوحة تحكم حديثة، إدارة العملاء، المعاملات والتأشيرات، حجوزات الباص، التقارير المالية، وتغيير كلمة المرور من داخل الحساب.

## التشغيل على Render

- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `gunicorn app:app`
- أضف متغيرًا سريًا باسم `SECRET_KEY` بقيمة طويلة وعشوائية.
- يمكن إضافة `COOKIE_SECURE=1` عند تشغيل الموقع عبر HTTPS.

يتم إنشاء جداول SQLite تلقائيًا عند أول تشغيل. قاعدة البيانات الحالية لا تُحذف عند تحديث القوالب؛ احرص على استخدام قرص دائم في Render إذا كانت الخطة تدعم ذلك، لأن SQLite داخل بيئة مؤقتة قد تفقد البيانات عند إعادة النشر.

## تسجيل الدخول

يجب أن يكون حساب المدير موجودًا في قاعدة البيانات. لم يعد مسار إنشاء المدير المفتوح متاحًا لأسباب أمنية. بعد الدخول استخدم **إعدادات الحساب ← تغيير كلمة المرور**، واختر كلمة مرور لا تقل عن 8 أحرف أو أرقام.

## التطوير المحلي

```bash
pip install -r requirements.txt
python app.py
```

ثم افتح `http://localhost:5000`.
