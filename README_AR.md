# نظام النسيم للسفريات – النسخة الأولى

نظام ويب بسيط لإدارة مكتب النسيم للسفريات، ويعمل على الكمبيوتر والجوال عبر المتصفح.

## الموجود في النسخة الأولى
- لوحة تحكم
- العملاء والبحث عنهم
- معاملات التأشيرات والخدمات
- المدفوع والمتبقي والمصروف والربح
- تقارير حسب نوع الخدمة
- قاعدة بيانات SQLite محلية

## التشغيل على الكمبيوتر
1. ثبّت Python 3.11 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   pip install -r requirements.txt
4. ثم:
   python app.py
5. افتح المتصفح على:
   http://127.0.0.1:5000

## ملاحظة
هذه نسخة أولى للتجربة. قبل استخدامها ببيانات عملاء حقيقية يجب إضافة تسجيل دخول قوي، نسخ احتياطي، تشفير/حماية الملفات، وإعدادات استضافة آمنة.
